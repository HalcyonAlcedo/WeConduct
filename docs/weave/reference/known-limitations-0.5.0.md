# Weave 0.5.0 已知限制

- 与 WeConduct 没有直接同步接口，只能人工传递选择器、URL、请求信息、Cookie 和存储值。
- 网络捕获面板没有重放按钮；后端重放 API 不是 0.5.0 内置 UI 工作流。
- 存储面板不能新增 Cookie，也没有一键清空全部 Local/Session Storage 的按钮。
- 插件文档只覆盖发现、启用、状态和面板使用，不提供插件开发说明。
- 没有内置自动更新，更新需手动替换 `Weave.exe` 和同版本附带文件。
