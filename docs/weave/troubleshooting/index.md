# 故障排查

## 程序启动了，但没有任何历史数据

先检查 `Weave.exe` 同级是否存在 `.weave\`。Weave 的工作区、设置和会话状态默认都保存在这里；如果你换了程序目录，相当于换了一套数据根目录。

## 工作区按钮灰掉了

这是正常保护。会话运行中时，工作区切换、新建和删除都会被禁用。先停止会话，再改工作区。

## 找不到“设置”“网络捕获”“存储管理”或“拦截规则”

这些面板默认可能不在当前布局里。用顶部“窗口”菜单把它们放回左栏、中栏或右栏，或者直接点击“恢复默认布局”。

## 页面树没有内容

按这个顺序看：

1. 会话是否真的处于“运行中”。
2. 页面树面板是否还在“加载中…”。
3. 当前页面是否已经完成初步渲染。
4. 停止后重新启动会话，再看是否恢复。

## 叠加层看不到

优先检查：

- “叠加层可见”是否已勾选
- 当前会话是否仍在运行
- 是否误开了“鼠标穿透”导致你以为浮层失效
- 点击“重置位置”后是否恢复

## 只想新增 Cookie，但界面里没有入口

这是 0.5.0 的现实限制。当前内置 UI 只能删除 Cookie，不能直接新增 Cookie。

## 想重放请求，但网络面板里没有按钮

这也是 0.5.0 的现实限制。后端有重放 API，但内置网络面板没有重放 UI。

## WeConduct 没有自动收到 Weave 里的结果

这是正常现象。两者没有直接同步接口，必须人工复制选择器、Cookie、存储值或请求数据。
