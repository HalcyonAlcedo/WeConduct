# Weave

Weave 0.5.0 当前作为独立软件记录文档入口。它可以与 WeConduct 手工协作使用，但没有直接同步接口。

## 产品边界

- Weave 是独立软件，不依赖 WeConduct 进程内集成。
- 当前仅支持可选的手工协作流程，例如人工对照工作区内容、会话结果或页面分析结论。
- 当前没有 WeConduct 与 Weave 之间的直接同步接口、自动导入接口或联动 API。
- 目前暂无公开 Release/分发文件。
