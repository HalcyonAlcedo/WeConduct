# 插件

## 用户侧要知道的边界

本页只覆盖 0.5.0 的用户操作，不讨论插件开发 API。

## 插件目录

Weave 启动时会扫描 `Weave.exe` 同级的 `plugins\` 目录。打包脚本也会在发布目录里预建这个文件夹。

## 插件管理能做什么

设置页里的“插件管理”用于决定哪些已识别插件会在启动时实际加载。

界面会显示：

- 名称或插件 ID
- 状态
- 类型
- 版本
- 错误信息

## 常见状态

- `已加载`
- `未启用`
- `插件自禁用`
- `加载失败`
- `已发现`

## 启用或停用插件

1. 打开“设置 -> 插件管理”。
2. 勾选或取消勾选插件。
3. 点击“保存”。

0.5.0 的启用列表最终写入 `ui_defaults.enabled_plugins`，按插件 ID 一行一个保存。

## 插件面板

如果插件声明了自己的面板，它会和内置面板一起出现在“窗口”菜单中。你可以像移动其他面板一样，把插件面板放到左栏、中栏或右栏。

## 状态栏里的插件摘要

底部状态栏会显示外部插件数量摘要。这里只统计外部插件，不把内置面板算进去。
