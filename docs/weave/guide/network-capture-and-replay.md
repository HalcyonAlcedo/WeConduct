# 网络捕获

网络捕获面板用于记录和查看浏览器会话中的 HTTP 请求和响应。

## 网络面板能做什么

在有活跃会话后，打开"网络捕获"面板，你可以：

- 开始或停止捕获
- 清空已捕获记录
- 按 URL 过滤
- 查看请求和响应的详情

## 基本操作

1. 启动浏览器会话。
2. 打开"网络捕获"面板。
3. 点击 **捕获** 开始记录，按钮会切换为 **停止**。
4. 在页面中触发网络请求。
5. 点击列表中的某一行查看详情。

列表行会显示请求方法、状态码、MIME 类型、URL 预览和响应大小。

## 查看请求详情

选中一条记录后，详情区会展示：

- 请求 Headers 和 Body
- 响应 Headers 和 Body

JSON 格式的响应会自动格式化显示，其他内容按文本截断显示。响应体当前最多展示前 5000 个字符。

!!! note "关于请求重放"
    0.5.0 的网络捕获面板暂不支持在内置界面中直接重放请求。如果需要重放，可以复制请求信息后在 WeConduct 中使用 HTTP 请求节点来发送。
