# 网络捕获与重放

## 网络面板能做什么

“网络捕获”面板在有活跃会话后可用。它的内置 UI 支持：

- 开始或停止捕获
- 清空已捕获记录
- 按 URL 过滤
- 查看请求和响应详情

## 基本操作

1. 启动会话。
2. 打开“网络捕获”面板。
3. 点击 `⏺ 捕获` 开始记录，按钮会切成 `⏸ 停止`。
4. 在页面里触发请求。
5. 点击某一行查看详情。

列表行会显示：

- 请求方法
- 状态码
- MIME 类型
- URL 截断预览
- 大小

## 详情区内容

选中一条记录后，下面会显示：

- 请求 Headers
- 请求 Body
- 响应 Headers
- 响应 Body

JSON 响应会自动格式化；其他内容会按文本截断显示。响应体当前最多展示前 5000 个字符。

## 关于“重放”

0.5.0 后端确实提供了 `/api/weave/network/replay` 接口，但内置“网络捕获”面板当前没有“重放”按钮，也没有对应表单。

因此这页标题里的“重放”要按下面理解：

- 程序能力层面：存在重放 API。
- 内置用户界面层面：0.5.0 还没有现成的重放操作入口。

如果你只使用桌面界面，请把 0.5.0 视为“可捕获、可查看，暂不可在内置面板中直接重放”。
