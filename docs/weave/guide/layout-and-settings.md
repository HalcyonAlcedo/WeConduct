# 布局与设置

## 默认布局

首次没有布局文件时，工作台默认是：

- 左栏：工作区 + 页面树
- 中栏：节点详情
- 右栏：叠加层 + 搜索
- 中栏顶部：固定会话条

左右栏宽度默认分别为 `26%` 和 `24%`。

## 调整布局

0.5.0 支持这几种布局操作：

- 拖动左右分隔条调宽度
- 把面板拖到左栏、中栏或右栏
- 在“窗口”菜单里把面板放到指定栏位
- 从“可恢复窗口”列表恢复被关闭的面板
- 用“恢复默认布局”回到默认状态

## 打开隐藏面板

有些面板默认不显示，例如：

- 设置
- 网络捕获
- 存储管理
- 拦截规则

打开方法是顶部菜单“窗口”，然后把对应面板放到左栏、中栏或右栏。

## 设置页的三个标签

设置面板有三部分：

- 软件设置
- 插件管理
- 插件设置

在独立 `/settings` 路由下是左侧导航，在工作台内嵌面板下是顶部标签页。

## 软件设置里已有的内置项

0.5.0 内置 schema 已公开的设置包括：

- 自动恢复上次工作区
- 自动加载最近会话快照
- 删除工作区前确认
- 默认起始地址
- 默认无头模式
- 浏览器路径覆盖
- 浏览器关闭后自动结束会话
- 记住窗口大小和位置
- 启动时最大化
- 主题模式
- 记住布局
- 自动恢复上次布局
- 默认布局预设
- 启用插件列表
- HTTP 调试接口开关与端口

高级项需要先在设置工具栏勾选“显示高级”。
