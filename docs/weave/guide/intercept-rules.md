# 拦截规则

## 面板入口

“拦截规则”面板默认不显示，需要通过“窗口”菜单放到左栏、中栏或右栏。

## 能配置什么

每条规则都包含这些核心字段：

- URL 匹配模式
- 拦截阶段：请求 / 响应
- 动作：修改 / 替换 / 阻断
- 优先级
- 是否启用

还能编辑：

- 请求头修改
- 响应头修改
- 请求体
- 响应体
- 响应状态码

## 新建规则

1. 启动会话。
2. 打开“拦截规则”面板。
3. 点击 `+ 新增规则`。
4. 填写 URL 匹配模式，例如 `*.api.example.com/*`。
5. 选择阶段、动作和优先级。
6. 按需填写头、Body 或状态码。
7. 点击“保存”。

## 列表区操作

- 点击一行：选中并进入编辑。
- 点击左侧 `✓` / `✗`：直接启用或停用规则。
- 点击右侧 `🗑`：删除规则。

## 使用建议

- 先用较高优先级数字区分临时规则和长期规则。
- 只改你确认需要的头或 Body，避免把无关响应一并改坏。
- 需要整体替换响应时，再用“替换”；只改部分头字段时优先用“修改”。
