# 叠加层与检查模式

## 面板作用

“叠加层”面板负责控制浏览器页面中的分析浮层。没有会话时，这个面板只会提示“启动会话后可控制分析态叠加层”。

## 四个开关

- `叠加层可见`
- `检查模式`
- `锁定位置`
- `鼠标穿透`

## 使用建议

1. 先打开 `叠加层可见`，确认浮层已经注入页面。
2. 再打开 `检查模式`，用页面悬停高亮元素。
3. 需要固定浮层位置时再打开 `锁定位置`。
4. 需要让鼠标直接点穿浮层时，打开 `鼠标穿透`。

## 一个容易忽略的联动

打开“鼠标穿透”时，Weave 会同时把“锁定位置”设为开启，并禁用“锁定位置”复选框。这是 0.5.0 的实际界面行为，不是文档建议。

## 面板里能看到的状态

- 选中节点
- 悬停节点
- 叠加层位置
- 定位锚点
- 位置锁定状态
- 鼠标穿透状态

## 重置位置

点击“重置位置”会把浮层位置恢复到：

- `position_x = 12`
- `position_y = 12`
- `position_anchor = top-left`

如果你觉得浮层跑到屏幕边缘，先用这个按钮恢复。
