# 工作区

## 工作区是什么

Weave 的工作区用于隔离起始 URL、布局和会话关联状态。每个工作区都会落到 `.weave\workspaces\<workspace_id>\` 目录下。

工作区摘要会记录：

- `workspace_id`
- `workspace_name`
- `workspace_dir`
- `last_start_url`

## 打开工作区面板

- 默认布局左栏会显示“工作区”面板。
- 顶部菜单“文件 -> 新建工作区”也会打开创建对话框。

## 新建工作区

1. 在工作区面板点击 `+ 新建`，或用菜单“文件 -> 新建工作区”。
2. 输入名称。
3. 点击对话框里的“确定”。

创建成功后，Weave 会切换到新工作区，并刷新当前会话相关状态。

## 切换工作区

- 在工作区列表中点击目标行即可切换。
- 当前工作区会高亮显示名称。

切换后，起始 URL 会按该工作区保存的 `last_start_url` 回填到会话栏。

## 删除工作区

1. 在工作区列表中找到目标工作区。
2. 点击行尾 `✕`。
3. 在确认对话框中确认删除。

删除会移除该工作区目录。若删掉的是当前工作区，Weave 会切换到新的活动工作区；如果没有剩余工作区，则进入空状态。

## 运行中限制

会话运行时，工作区面板会显示 `会话运行中，不可变更工作区`，此时：

- 不能新建工作区。
- 不能切换工作区。
- 不能删除工作区。

要改工作区，先停止会话。
