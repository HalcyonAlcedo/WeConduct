# 页面树与搜索

## 页面树面板

默认布局左栏下半部分是“页面树”。没有会话时会显示“启动会话后可查看页面树”。

## 两种查看模式

页面树会按面板宽度自动切换：

- 宽度不足或你输入筛选词时，显示列表模式。
- 宽度达到阈值且筛选框为空时，显示树图模式。

## 列表模式能做什么

- 按层级浏览节点。
- 点击行选择节点。
- 点击节点前的箭头折叠或展开子树。
- 看到折叠节点的子节点数量。
- 在顶部筛选框按标签名或文本筛选。

## 树图模式能做什么

- 以卡片图查看节点层级。
- 鼠标滚轮缩放。
- 在空白区域拖动画布。
- 点击卡片选择节点。
- 点击卡片右上角 `+` / `−` 折叠或展开。
- 用右下角工具按钮 `↺` 重置视图，`⊡` 适应窗口。

## 右键菜单

无论列表模式还是树图模式，右键节点都可以复制：

- 节点 ID
- 标签名
- 文本
- 选择器

## 搜索面板

独立的“搜索”面板和页面树顶部筛选不是一回事：

- 页面树筛选只过滤当前树视图。
- 搜索面板会调用会话搜索接口，支持“标签 / 文本 / 选择器”检索。

搜索面板操作很直接：

1. 输入关键字。
2. 点击“搜索”或回车。
3. 点击结果项跳转并选中对应节点。
4. 点 `✕` 清除当前搜索结果。
