# 节点详情与选择器

## 如何打开节点详情

默认布局中栏内容区会显示“节点详情”。先在页面树、树图或搜索结果里选中一个节点，再看这里。

## 节点详情里有什么

0.5.0 会按区块展示四类信息：

- 当前节点：节点 ID、父节点 ID、标签名、文本、快照选择器、子节点统计
- 运行时摘要：元素描述、运行时选择器、角色、元素 ID、类名、值、位置尺寸、可见性、可交互性、动态标志
- 页面状态：标题、加载状态、当前 URL、当前选中节点 ID、当前悬停节点 ID、运行时注册节点数、叠加层状态
- 会话信息：当前 URL、启动 URL

如果当前有悬停元素，还会额外显示“悬停摘要”。

## 复制方式

每个字段右侧都有复制按钮 `⎘`。复制成功后，界面会短暂提示“已复制：字段名”。

## 两类选择器要区分

- `快照选择器`：来自页面树快照，适合先做结构定位。
- `运行时选择器`：来自当前运行时摘要，适合配合叠加层或外部流程做现场定位。

两者不保证完全一样。页面有动态渲染、临时节点或延迟加载时，优先人工核对运行时选择器。

## 给 WeConduct 使用时的建议

如果你要把结果带回 WeConduct，优先复制：

- 运行时选择器
- 当前 URL
- 元素文本或元素描述

这样更容易在 WeConduct 的 `selector` 字段里复现定位目标。
