# 浏览器会话

## 会话入口

Weave 把会话控制固定放在中栏顶部的会话条里，同时还有一个可恢复的“会话控制”面板内容视图。

常用入口：

- 顶部工具栏 `▶ 启动` / `■ 停止`
- 中栏会话条里的 URL 输入框和 `▶` / `■`
- “窗口”菜单里把“会话控制”放回左栏、中栏或右栏

## 启动会话

1. 在会话条或会话控制面板输入 URL。
2. 点击 `▶ 启动` 或 `▶ 启动会话`。
3. 等待页面打开后，Weave 会自动拉取页面树并同步运行时状态。

当前工作区里的起始 URL 会在输入时自动保存，启动前还会再立即保存一次。

## 停止会话

- 点击 `■ 停止`。

停止后会话状态会切换为“已停止”，叠加层状态也会同步更新。

## 会话状态

0.5.0 的状态文案只有三种：

- `◉ 空闲`
- `● 运行中`
- `■ 已停止`

完整面板里还能看到：

- 会话 ID
- 快照 ID
- 当前选中节点 ID

## 0.5.0 的几个现实边界

- 桌面界面没有“无头模式”开关，当前启动调用固定传 `false`，即按可见浏览器启动。
- 输入框在会话运行中会禁用，避免中途改 URL。
- 页面树、搜索、叠加层、网络、存储、拦截规则都要求先有活跃会话。
