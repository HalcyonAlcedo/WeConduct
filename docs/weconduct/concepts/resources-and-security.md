# 资源与安全

项目资源包括项目自有文件、资源索引、覆盖配置以及组件或子图资源。保存项目时，这些内容与主图、项目设置一起写入项目目录化存储。

## 路径范围

相对资源路径优先以项目目录解析。文件读写、导入、导出和包加载都会检查允许的根目录与目标路径。迁移项目时应移动整个目录，以免相对路径失效。

## 权限开关

0.8.1 对高风险能力使用运行设置和安全策略控制，例如：

- 本地与远程网络访问
- Python 执行
- JavaScript 注入与求值
- 文件读写和外部资源
- 浏览器 Cookie、存储和下载操作

功能被禁用时，节点应返回明确错误或安全事件，而不是静默放行。不要为了让单个示例运行而全局开启所有权限。

## 最小授权

0.8.1 的默认值不是“全部关闭”：受限范围内的文件访问、浏览器截图、Cookie、浏览器存储、上传和新窗口默认允许；外部程序、浏览器执行器、浏览器下载、本地/远程网络、Python 执行、JavaScript 注入与求值默认关闭。高风险操作确认和运行时安全警告默认开启。

文件访问虽然默认允许，但默认 `file_access_scope = "restricted"`，不等于允许访问任意路径。

建议按以下顺序管理权限：

1. 保留当前默认值，先运行一次并读取诊断。
2. 根据错误代码确认具体缺少的能力，不要批量开启所有开关。
3. 只为当前项目开启必要权限，并保持文件根目录和扩展名范围尽量窄。
4. 运行完成后复核项目设置、网络目标和外部文件输出。

`.wcrun` 包在加载前还会执行预检，汇总资源、依赖、外部绑定与运行环境就绪状态。未知来源的包不应直接授予 Python、脚本注入或广泛文件权限。
