# 变量、类型与表达式

在自动化流程中，你经常需要把数据从一个节点传到另一个节点。WeConduct 使用**变量**来存储这些数据，使用**表达式**来做条件判断和简单计算。

## 变量的基本操作

### 创建变量

有两种常见方式创建变量：

- 在**开始节点**中设置 `initial_variables`，流程启动时就会预先定义好这些变量
- 使用**写入变量**节点（`data.set_variable`）在流程执行过程中动态创建或更新变量

### 读取变量

使用**读取变量**节点（`data.get_variable`）按名称读取变量值。如果变量不存在，读取结果是 `null`。

### 值的类型

变量可以存储多种类型的值：

- **字符串**：`"hello"`、`"https://example.com"`
- **数字**：`42`、`3.14`
- **布尔值**：`true`、`false`
- **空值**：`null`
- **列表**：`[1, 2, 3]`、`["a", "b", "c"]`
- **对象**：`{"name": "张三", "age": 30}`

建议让变量保持其原始的数值类型，不要为了方便显示而提前把所有值都转成字符串。比如数字 `5` 保留为数字类型，后续的数学运算或排序操作会更准确。

## 变量引用语法

在任何节点的配置参数中，你都可以用 `${...}` 格式引用变量或节点输出：

| 写法 | 含义 |
|------|------|
| `${message}` | 读取变量 `message` 的值 |
| `结果：${message}` | 把变量值嵌入文本中 |
| `${message|string}` | 读取后转换为指定类型 |
| `${node.node-2.body}` | 读取节点 `node-2` 输出中的 `body` 字段 |

引用可以出现在列表和对象内部，运行时会递归解析所有 `${...}` 标记。

### 类型保留

- 如果整个配置字段就是一个 `${变量名}`，值的原始类型会被保留。比如 `${counter}` 是数字 `5`，传到下游也是数字。
- 如果把引用嵌在普通文本中，比如 `"当前计数：${counter}"`，整个值会变成字符串 `"当前计数：5"`。

## 表达式

部分节点（如条件判断 `control.if`、重试 `control.retry`）支持写表达式来决定行为。WeConduct 使用一种安全的受限表达式语法，不会执行任意的 Python 代码。

支持的操作包括：

- 比较运算：`==`、`!=`、`<`、`>`、`<=`、`>=`
- 逻辑运算：`and`、`or`
- 数学运算：`+`、`-`、`*`、`/`、`//`
- 列表下标访问：`list[0]`
- 长度函数：`len(value)`
- 字典取值：`dict.get(key, default)`

示例：
```text
counter < 3
user_name == "admin"
left_done and right_done
len(items) > 0
```

表达式应该保持简短。如果需要复杂的数据处理逻辑，建议使用 Python 执行节点而不是堆砌复杂的表达式。
