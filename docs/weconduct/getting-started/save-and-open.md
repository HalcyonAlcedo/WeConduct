# 保存和重新打开项目

## 保存项目

使用 **文件 → 保存项目** 保存当前主图、项目设置和项目资源。首次保存且项目尚无路径时，WeConduct 会转入 **另存为**。

如果当前编辑的是自定义组件图，保存项目仍会读取并保存主图，同时保留自定义图资源。

## 目录项目

0.8.1 的项目以 `.weconduct.json` 主文件所在目录作为工作区根目录。保存时程序还会维护节点图、项目设置和项目自有资源的目录化存储。

因此：

- 备份或迁移时复制整个项目目录。
- 不要手工修改一半文件后继续运行。
- 项目内相对资源路径以项目目录为重要解析根。

## 打开项目

1. 选择 **文件 → 打开项目**。
2. 选择项目的 `.weconduct.json` 文件。
3. 等待工作区、主图、资源、运行记录和设置刷新完成。

最近项目列表保存的是项目路径。若目录已移动，可从列表移除旧记录，再从新位置打开。

## 只读运行包

`.wcrun` 是运行分发包，不是普通可编辑项目。加载后来源标记为 `wcrun_package`，项目保存、另存和图修改受限；只允许调整运行默认值范围内的内容。需要编辑图时，应打开原始项目目录。

相关概念：[项目与工作区](../concepts/projects-and-workspaces.md)。
