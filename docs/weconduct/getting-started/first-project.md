# 创建第一个项目

这个例子会带你从零开始创建你的第一个 WeConduct 项目——一个简单的流程：写入一个变量，再把它读出来。整个过程只需要几分钟。

<weconduct-graph src="../../assets/graphs/getting-started/first-project.json" title="第一个项目：写入并读取变量">如果图示加载失败，请按照下方的步骤操作即可。</weconduct-graph>

## 第 1 步：新建项目

1. 点击顶部菜单的 **文件 → 新建项目**。
2. 在项目名称栏输入 `first-project`。
3. 选择一个你方便找到的目录来存放项目文件。
4. 点击确认，项目就创建好了。

项目创建后，WeConduct 会在你选择的目录中生成一个主文件 `first-project.weconduct.json` 以及配套的项目数据目录。迁移或备份项目时，请把整个项目目录一起移动，不要只复制单个文件。

## 第 2 步：添加节点

从左侧的 **组件库** 面板中依次拖入三个节点：

1. **开始** — 每个流程都必须有一个开始节点，它是整个流程的入口。
2. **写入变量** — 用来设置一个变量的值。
3. **读取变量** — 用来读取之前写入的变量值。

> 提示：你可以在组件库中搜索"开始"、"写入变量"、"读取变量"来快速找到它们。

## 第 3 步：配置参数

点击每个节点，在右侧的节点配置面板中填写参数：

**开始节点**：
- 保持默认配置即可，不需要额外修改。

**写入变量节点**：
- `name` 填 `"message"`
- `value` 填 `"WeConduct 0.9.1"`

**读取变量节点**：
- `name` 填 `"message"`

这样，"写入变量"会创建一个名为 `message`、值为 `"WeConduct 0.9.1"` 的变量，"读取变量"会把它读出来。

## 第 4 步：连接节点

用鼠标从每个节点的输出端口拖到下一个节点的输入端口，建立控制连线：

1. `开始.out` → `写入变量.in`
2. `写入变量.out` → `读取变量.in`

控制连线决定了节点的执行顺序。这个例子中不需要数据连线，因为"读取变量"是通过变量名直接从运行时变量表中取值的。

## 第 5 步：保存项目

点击 **文件 → 保存**。如果这是你第一次保存这个项目，程序会提示你选择保存位置。

保存成功后，窗口标题栏应该不再显示"未保存"的标记。

## 第 6 步：运行！

点击顶部工具栏的 **运行** 按钮。WeConduct 会自动完成编译、检查和执行——你不需要手动做任何额外操作。

如果一切顺利，任务执行面板会显示运行成功。点击"读取变量"节点，你可以在结果中看到：

```json
{
  "variable_name": "message",
  "value": "WeConduct 0.9.1"
}
```

恭喜！你已经完成了第一个 WeConduct 自动化流程 🎉

## 如果运行失败了

先打开底部的 **输出** 面板，查看诊断信息。最常见的原因是：
- 某个参数忘记填写了
- 控制连线没有正确连接到 `in` 端口
- 主图中没有开始节点

记下报错信息中的节点 ID 和错误描述，通常就能快速定位问题。
