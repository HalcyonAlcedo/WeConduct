# 第一次运行

标准运行以当前主图为输入。顶部运行按钮与任务执行界面的运行操作进入同一后端执行链。

## 运行前

确认以下条件：

- 已打开可编辑项目，而不是只读 `.wcrun` 包。
- 主图包含且只包含一个 `flow.start`。
- 所有必填配置已填写，控制边连接到存在的端口。
- 当前没有标准运行或 Debug 会话占用执行控制。

## 启动与状态

点击运行后，WeConduct 会同步当前节点图，自动准备运行环境，编译图并启动执行会话。运行期间运行按钮会变为终止操作；不要连续重复点击。

任务执行面板显示会话状态和进度。**输出**面板显示运行消息，其中的 **诊断** 标签汇总与当前项目有关的编译、运行和 Debug 诊断。

## 成功与失败

以后端会话终态为准：

- 成功：流程达到正常结束，任务执行面板显示成功。
- 失败：节点返回失败、编译失败或运行环境准备失败。诊断中应保留错误代码、节点或阶段信息。
- 已终止：用户点击终止，后端完成取消和收尾后进入终态。

前端提示与任务执行面板不一致时，重新读取任务状态和诊断，不要只根据一次 toast 判断结果。

## 终止运行

运行期间可点击顶部终止按钮或任务执行面板中的终止操作。0.8.1 默认立即提交终止请求；正在执行的底层操作仍需要完成取消检查和资源收尾。

下一步：[保存和重新打开项目](save-and-open.md)。
