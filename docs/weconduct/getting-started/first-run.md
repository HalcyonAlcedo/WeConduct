# 运行你的流程

点击运行按钮后，WeConduct 会自动把你的流程图编译成可执行的会话，然后从开始节点一步步执行。这一页帮你理解运行过程中发生了什么，以及如何判断运行结果。

## 运行前检查

点击运行前，快速确认以下几点：

- 你打开的是一个可编辑项目（不是只读的 `.wcrun` 打包文件）
- 主图中有且只有一个开始节点（`flow.start`）
- 所有节点的必填参数都已经填好
- 控制连线都连接到了实际存在的端口上
- 没有其他运行或调试会话正在占用执行引擎

## 点击运行后发生了什么

1. **同步**：WeConduct 把画布上当前的流程图作为本次运行的输入。
2. **自动准备**：检查图的结构、资源引用、安全权限和 Python 运行环境（如果用到的话）。
3. **编译**：把流程图转成后端可执行的指令序列。
4. **执行**：从开始节点出发，按控制连线的顺序逐个执行节点。
5. **完成**：所有节点执行完毕后会话结束；执行过程中也可以点击终止按钮提前结束。

运行期间，顶部的运行按钮会变成终止图标，任务执行面板会实时显示每个节点的执行状态。

## 运行结果怎么看

打开底部的 **输出** 面板，你可以看到：

- **运行消息**：按时间顺序记录的执行日志。
- **诊断信息**：汇总了编译、运行和调试相关的所有警告和错误。

### 成功的标志

流程正常执行完毕，任务执行面板显示为"成功"状态。点击任意节点可以查看它的执行结果和输出数据。

### 如果失败了

任务执行面板会显示"失败"状态。失败的原因可能是：
- 某个节点在执行时出错（比如浏览器操作找不到目标元素）
- 图编译失败（比如有节点没连接、端口使用不正确）
- 运行环境准备失败（比如权限没开、资源找不到）

打开诊断信息，从第一条错误开始排查，通常就能找到根因。

## 终止运行

如果需要中途停止执行，点击顶部的终止按钮即可。WeConduct 会立即提交终止请求，正在执行的操作会完成必要的清理后退出。

终止后的会话状态显示为"已终止"，你可以查看执行到哪一步时被中断的。
