# 资源管理

打开 **视图 → 资源管理** 查看内置组件和项目用户组件。可按分类和标签筛选。

## 内置资源

内置组件可启用/禁用并添加项目标签。禁用资源不会从历史图中删除，但新建和运行会受到可用性检查。内置实现不写入项目目录，项目只保存引用和覆盖。

## 用户组件

资源管理支持新建、重命名、打开、启用/禁用、编辑标签、查看 schema、导入导出和删除 `custom_node_graph`。删除不可撤销，先检查主图和其他组件是否引用它。

## 子图资源导出

选中一个用户组件后，在资源管理页面选择 **导出子图**，再在系统文件对话框中选择任意本地目标位置。导出文件使用 `.wcsubgraph` 扩展名，是独立的单文件资源包，不是 `.wcrun` 项目包。

导出包只包含该子图的图数据、实际引用的递归用户组件依赖，以及必要的资源格式和校验元数据。它不包含项目名称、项目路径、项目设置、运行状态或项目级嵌入资源。

## 子图资源导入

选择 **导入子图** 后，先选择 `.wcsubgraph` 文件。程序会在预检阶段检查容器安全性、资源包格式、版本兼容性、图数据、内置节点依赖和用户组件依赖；同时限制归档最多 256 个文件、解压后总大小不超过 64 MiB。预检失败时不会写入当前项目。

预检通过后，需要明确选择冲突策略并确认提交：

- `abort`：发现冲突时中止导入；无冲突时系统默认采用此策略并正常完成导入。发现冲突后请取消操作，或改选下面两种解决策略。
- `rename`：为冲突资源分配新 ID，并同步重写包内图和依赖引用。
- `replace`：明确确认后替换同 ID 资源；schema 不兼容时拒绝替换。

提交成功后，资源目录和组件库会刷新。导入只改变当前项目的用户组件资源，不会覆盖目标项目已有的嵌入文件或修改项目级资源策略。

## 嵌入与外部资源

- **嵌入资源**：构建 `.wcrun` 时复制进包，适合需要随包分发的固定文件。
- **外部资源**：包中只保存绑定声明，加载后需要在 **外部绑定** 中提供路径或值。

项目路径、资源索引和覆盖文件见[项目布局](project-layout.md)。文件访问仍受程序安全权限和允许根限制。

## 当前支持的操作

0.9.1 的资源管理面板支持：新建、打开、启用/禁用、编辑标签、查看 schema、导出 `.wcsubgraph`、导入 `.wcsubgraph` 和删除用户组件。
