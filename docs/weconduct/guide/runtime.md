# 标准运行

标准运行从当前主图创建后端执行会话。顶部运行按钮与任务执行面板进入同一执行链。

## 生命周期

1. **同步图**：把未保存的当前图作为本次运行输入。
2. **自动准备**：检查图、资源、权限和项目 Python 环境；无需手动点击 Prepare。
3. **编译**：依次完成 parse、bind、validate、normalize、lower 和 emit。
4. **启动**：会话进入准备或运行状态，从唯一 `flow.start` 调度。
5. **进度**：节点状态、事件和变量持续写回会话。
6. **收尾**：正常耗尽队列后进入 `completed`，结果状态为 `succeeded`；错误进入 `failed`，用户终止进入 `aborted` 或取消终态。

UI 提示与会话状态不一致时，以后端会话终态和诊断为准。

## 运行期间

运行按钮会切换为终止。任务执行面板显示会话，**输出**面板显示消息、诊断、摘要和历史。标准运行期间不能同时启动 Debug。

## 加密参数解锁

如果项目设置了加密初始参数，启动结果会先进入 `unlock_required`，不会启动执行 worker。UI 会弹出密码窗口；外部 API 调用 `execution.parameters.unlock`，CLI 在当前终端输入密码。密码校验成功后才进入 `running` 或 `waiting`，错误密码不会把参数明文写入诊断。

解锁状态只属于当前执行会话。终止会话会同时关闭解锁窗口并撤销内存中的敏感引用；不能把一次运行的解锁结果当作下一次运行的缓存。

## 待输入与超时

`input.request` 会暂停**整个执行会话**，而不是只暂停某个逻辑分支。请求可以包含多个字段，并按字段生成独立输出端口；UI 使用独立输入窗口，CLI 在终端输入，外部 API 通过 pending-input 查询和提交接口输入。

- 标记为敏感的字段不允许设置默认值，字段值只存在当前会话内存中。
- 非敏感字段可以提供默认值；待输入 GET、事件、日志和历史不会返回敏感字段值。
- `timeout_seconds > 0` 才启用超时；`0` 或负数表示不设置超时。
- 超时处理按固定顺序选择：节点为该字段设置的默认值 → 已连接的 `out.timed_out` 超时分支 → 节点失败。

输入表单验证成功后才会一次性提交所有字段。执行完成、取消或失败后，pending request 和敏感字段引用都会清理。

终止流程见[终止运行](runtime-abort.md)，历史见[执行历史](execution-history.md)。
