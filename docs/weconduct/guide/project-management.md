# 项目管理

## 新建项目

选择 **文件 → 新建项目**，填写项目名并选择项目目录。指定目录后，WeConduct 创建 `<项目名>.weconduct.json` 主文件和同名 `.data` 存储目录；未指定目录时项目先保存在当前工作区状态中，首次点击 **保存** 会进入 **另存为**。

## 打开与最近项目

选择 **文件 → 打开项目文件** 打开 `.weconduct.json`。打开完成后，程序会清理上一个项目的图草稿和编译源，再刷新节点图、资源、运行记录和 Debug 会话。

**文件 → 最近项目** 保存的是路径索引。移动项目目录后，从新位置重新打开，并移除失效的旧记录。

## 保存与迁移

- **保存**：写回当前路径。
- **另存为**：选择新的 `.weconduct.json` 路径。
- 备份或迁移：复制主文件及其同名 `.data` 目录，推荐直接复制整个项目目录。

桌面进程另有 `workspace-state.json`，用于保存当前工作区和恢复状态；它不是可分发的项目主文件，不应代替 `.weconduct.json` 备份。

## 三种项目形态

- **目录化项目**：0.8.1 的正常编辑形态，主清单引用 `.data` 目录中的图、资源和设置。
- **旧式单文件项目**：兼容载入旧 `.weconduct.json`，保存时同步生成目录化存储。
- **`.wcrun` 包**：用于分发运行，加载后只读，仅运行默认值可编辑。要修改节点图，应回到原始项目。

具体文件见[项目布局](project-layout.md)。
