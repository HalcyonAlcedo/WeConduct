# 终止运行

0.9.1 默认立即提交终止请求。点击顶部终止按钮或任务执行面板中的终止操作后，前端显示正在终止，后端取消上下文开始生效。

## 为什么不会瞬间结束

“立即”表示立即发出取消，不表示强制杀死进程。当前节点需要到达取消检查点；浏览器、文件、Python 或网络资源还需要关闭和结算。此阶段会话可能短暂保持 `aborting`。

## 正确判断

- 不要在 `aborting` 时重复启动新任务。
- 等待后端进入 `aborted`、`cancelled` 或其他终态。
- 若长时间不结束，记录 session ID、当前节点、最后事件和诊断，再报告问题。

## 等待解锁或待输入时终止

会话处于 `unlock_required` 或 `waiting` 时也可以终止。终止请求会使密码窗口或多字段输入窗口关闭，pending request 变为取消状态，后续迟到提交不会继续执行节点。

解锁密码、待输入敏感字段、`SensitiveRef` 和网络上下文临时资源都属于当前会话。终止完成后它们会从内存作用域撤销；显式通过文件节点保存的业务文件不由会话清理逻辑删除。

强制结束桌面进程可能留下浏览器或临时文件，只在正常终止无法完成时使用。
