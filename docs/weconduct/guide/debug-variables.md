# Debug 变量

Debug 变量面板按行显示变量名、类型、值、作用域和修改状态。只有活动会话可以编辑；历史快照只读。

## 类型化编辑

- 字符串直接输入。
- 整数和数字必须能解析为对应数值。
- 布尔值使用 `true` / `false`。
- 对象和数组使用 JSON。
- `null` 不可直接编辑。

错误值会留在当前行并显示原因，不会静默转换。

## 提交模式

- **立即提交**：回车或失焦后把该变量发送到活动会话。
- **暂存编辑**：本地保留多项修改，点击 **应用全部** 一次提交，或 **撤销全部** 丢弃。

0.9.1 默认使用 `staged` 暂存模式，可在程序设置中切换为 `immediate`。变量修改只影响当前 Debug 会话；不会改写 `flow.start.initial_variables` 或节点配置。

已修改行会以颜色和状态标记。对象/数组可用 `Ctrl+Enter` 提交当前编辑。

## 敏感变量

已解锁的加密参数和运行期派生敏感值在变量表中显示为脱敏引用，并带有敏感标记。暂停状态下可以点击 **查看敏感值**，再次输入项目参数密码后临时查看实际值；查看结果只保留在当前后端/前端内存响应中，不写入 Debug 历史、快照、日志或普通 API 响应。

继续、单步、再次暂停、终止或切换会话都会清除本次查看的明文。运行期修改敏感变量仍会保持敏感引用状态，并写入不含数值的 `warn` 审计事件；修改后的实际值不会进入日志。

Debug 的执行状态使用未脱敏的内存副本，持久化会话、事件、关键帧和历史使用脱敏投影。不要把浏览器开发者工具、屏幕录制或外部调试器当作安全边界。
