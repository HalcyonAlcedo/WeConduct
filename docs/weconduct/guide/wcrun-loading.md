# 检查和加载 `.wcrun`

在 **文件 → .wcrun 包管理 → 检查 & 加载** 选择包文件。

## 检查

**检查**只读取包并验证：

- manifest、包类型和版本
- 校验和
- 入口图与自定义组件图
- 内置/自定义依赖
- 嵌入/外部资源
- Python 运行时要求
- 当前环境运行就绪状态

检查不会切换当前工作区。

## 加载

**加载**验证并解压到临时会话目录，把工作区来源切换为 `wcrun_package`。图和项目设置只读，仅运行默认值可编辑。

包要求的安全权限未满足时会显示确认窗口。**忽略**可以继续查看，但运行可能被安全策略阻止；**一键修改并放行权限**会修改程序级安全配置，只有确认包来源和所需能力后才使用。

外部资源缺失时，在 **外部绑定** 输入 `resource_id` 和实际路径或值。绑定完成后重新检查运行就绪状态。

## 卸载

点击 **卸载** 清理包会话并恢复普通工作区。卸载不会修改原 `.wcrun` 文件。需要编辑流程时，打开用于构建它的原始项目。
