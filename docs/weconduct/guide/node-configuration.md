# 节点配置

每个节点的配置参数保存在节点自身的配置中。编辑器会根据节点的类型自动显示对应的配置控件，不同节点的配置界面会有所不同。

## 字段编辑器

节点配置面板会根据参数类型提供不同的编辑控件：

- **文本、数字、布尔值**：直接输入或切换开关。
- **类型化值**：可以区分字符串、数字、布尔、对象等不同类型，确保值的类型正确。
- **对象映射**：用于编辑变量表、输入输出映射等结构化数据。
- **复杂值**（分支列表、代码等）：建议在 **元数据编辑** 面板中完成，编辑空间更大。

节点上的行内摘要只展示最常用的字段，完整配置请切换到 **元数据编辑** 面板查看。

## 端口与配置

某些控制节点的配置会影响可用端口。修改配置后建议检查一下已有的连线，确保没有引用到被移除的端口。保存或运行时程序会自动校验端口是否正确。

## 保存冲突

如果多个窗口或异步刷新同时保存，可能会出现版本冲突。默认情况下程序会保留当前编辑的内容，你也可以在首选项中调整为更严格的冲突检查策略。

## 与 Debug 的边界

Debug 期间对变量值的修改属于临时会话状态，不会自动保存回节点的配置中。如果需要持久化 Debug 中的改动，请在节点配置面板中手动更新。
