# 图编辑器

## 添加与移动节点

在 **组件库** 中点击组件，或把组件拖到画布。拖放后是否自动打开属性由首选项控制。拖动节点会记录一次撤销快照；释放后位置写回图模型。

## 连接与断开

从输出端口拖到输入端口建立边。新边默认是控制边；点击边或使用边的右键菜单可在 `control` 和 `data` 间切换，但只有端口层匹配的边才会通过验证。

右键边选择删除，或选中后使用图组件提供的删除动作。删除节点时，与该节点相关的边会一并处理；是否要求确认由 **删除节点确认** 首选项决定。

## 复制与粘贴

右键节点选择 **复制节点**，再在右键菜单选择 **粘贴节点**。也可以先选中节点后使用 `Ctrl+C`，再按 `Ctrl+V`。文本框获得焦点或页面存在文本选区时，全局复制/粘贴不会抢占正常文本操作。

粘贴会基于当前视口中心生成位置，并为每次粘贴增加小幅偏移；节点草稿会获得新的 `node_id`、端口和锚点，只继承显示名与可编辑配置。主图不能粘贴第二个 `flow.start`，主图与自定义组件图也会限制不适用的边界节点。

## 配置与元数据

单击节点选择它；双击或右键 **查看属性** 打开 **元数据编辑** 面板。简单字段也可在节点上行内编辑，复杂的 `typed-value`、对象映射、代码和 `component-schema` 在面板中编辑更完整。

## 撤销与重做

- `Ctrl+Z`：撤销
- `Ctrl+Y`：重做
- `Ctrl+C` / `Ctrl+V`：复制/粘贴选中节点
- `Delete`：删除选中节点
- `Ctrl+B`：打开组件库
- `Ctrl+E`：打开源输入
- `Ctrl+Enter`：运行当前图

也可使用 **编辑 → 撤销/重做**。新编辑发生后，重做栈会清空。

## 面板布局

拖动面板标签到左、右、底部或中心区域。区域内多个面板以标签切换；拖动分隔条调整宽高。使用 **视图** 菜单显示/隐藏面板，或选择 **恢复默认布局**。

## 节点图首选项

在 **首选项** 中调整 `graph_preferences`，包括网格、吸附网格、拖放后自动打开节点、删除确认、行内配置摘要和保存冲突策略。设置只改变编辑体验，不会绕过图验证。
