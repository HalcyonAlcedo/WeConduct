# 术语表

- **项目**：根 `.weconduct.json` 与同名 `.data` 目录组成的可编辑工作单元。
- **工作区**：当前打开项目、面板布局和编辑状态的程序会话视图。
- **节点**：图中的执行、控制、观察或桥接单元，以 `resource_key` 标识能力。
- **端口**：节点的输入或输出连接点，分别属于控制、数据或观察关系层。
- **控制边**：决定节点执行顺序和结构分支的边。
- **数据边**：把上游输出值绑定到下游数据输入的边。
- **组件**：可从组件库添加的内置节点，或项目自定义节点图资源。
- **记录帧**：Debug 中不暂停执行但记录快照的节点标记。
- **快照**：断点、暂停、步进或记录帧事件冻结的变量与执行上下文。
- **运行时准备**：标准运行或 Debug 前的图、安全权限、资源和 Python 环境检查。
- **`.wcrun`**：从已保存项目构建的只读运行包。
- **外部绑定**：加载 `.wcrun` 后为未嵌入资源提供实际路径的会话配置。
