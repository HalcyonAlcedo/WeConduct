# 键盘快捷键

以下按 0.9.0 实际注册行为整理。

| 快捷键 | 行为 | 条件 |
|---|---|---|
| `Ctrl+Enter` | 启动标准运行 | 图非空，且没有活动运行或 Debug |
| `Ctrl+Z` | 撤销图编辑 | 当前图存在 |
| `Ctrl+Y` | 重做图编辑 | 当前图存在 |
| `Ctrl+C` | 复制选中节点 | 没有文本选区，焦点不在输入控件 |
| `Ctrl+V` | 粘贴节点 | 已复制节点，焦点不在输入控件 |
| `Delete` | 删除选中节点 | 按 `confirm_delete_node` 决定是否确认 |
| `Ctrl+B` | 打开组件库 | 全局 |
| `Ctrl+E` | 打开源输入 | 全局 |
| `Ctrl+K` | 清空源输入 | 焦点不在输入控件 |
| `Ctrl+S` | 显示“请使用 文件 → 保存”提示 | 0.9.0 不直接执行保存 |

## 已知问题

!!! warning "帮助窗口中显示但不可用的快捷键"
    `Ctrl+O`（打开项目）和 `Ctrl+N`（新建项目）在帮助窗口中列出，但 0.9.0 尚未注册这两个快捷键。请改用 **文件** 菜单中的对应选项。

`Ctrl+S` 在 0.9.0 中不会直接执行保存，而是显示提示引导你使用菜单。这是当前版本的设计选择。

Debug 变量编辑中，普通输入框按 `Enter` 提交，对象和数组编辑框使用 `Ctrl+Enter` 提交。历史变量和历史快照为只读。
